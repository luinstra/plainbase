Plainbase 0.5.0 redesigns the desktop workspace, from finding a page to editing it and discussing a passage.

## Changed

- **Calmer light and dark themes.** Warm paper surfaces, clearer contrast, readable labels and a
  simpler space switcher keep navigation compact. The header provides a wide search field and a
  single New page action.
- **Reading with context.** Page properties sit below the title, and the outline tracks the current
  section. Broken links explain their target and offer contextual actions. File paths and long
  inline code have copy controls; collapsed code can be expanded in place to read its full text.
- **One search palette.** Instant title matches and automatic content results share space filters,
  highlighted matches and keyboard navigation. Results are deduplicated by page, with body context
  instead of repeated headings.
- **Wider folder landings.** Folder cards show full titles with counts and paths, pages share a
  compact list, and New page here carries the current location into creation.
- **Focused page creation.** A dialog over the current view offers a readable folder picker, title,
  address preview and four starter templates. More options stay collapsed, and created pages open
  directly in the editor.
- **Write and Preview.** The editor keeps property chips, formatting tools, line numbers, save
  status and Discard together. Tables remain unwrapped, and broken-link markers help navigate
  drafts. Done returns to reading with unsaved-change protection. Search uses Cmd/Ctrl+K;
  inserting a link uses Cmd/Ctrl+Shift+K.
- **Discussions in context.** Visible discussions update automatically. Initials, status pills and
  All/Open/Resolved filters organize loaded threads. Opening a matched passage discussion
  highlights its source block, with source-version checks preventing stale highlights.

## Before upgrading

- Custom themes can use `--pb-surface-chrome` for the header and sidebar;
  `--pb-surface-raised` continues to control cards and panels.
- The storage and authentication model is unchanged. Continue backing up source files and each
  root's `.plainbase/discussions/` collection. When upgrading from before 0.4.0, also follow the
  [0.4.0 upgrade notes](https://github.com/luinstra/plainbase/releases/tag/v0.4.0).

## Maintenance

- Independent CI verification jobs now run in parallel.
- Browser checks wait for rendered metadata and popup navigation before asserting page content,
  avoiding timing failures while retaining contrast and navigation checks.
