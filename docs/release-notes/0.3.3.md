Plainbase 0.3.3 adds callouts and task lists to Markdown, plus read-only views for standalone Mermaid files.

## Added

- **Inline callouts.** GitHub-style `NOTE`, `TIP`, `IMPORTANT`, `WARNING`, and `CAUTION` blocks render in pages and editor previews, including nested Markdown content.
- **Task lists.** GFM task-list checkboxes render as checked or unchecked, display-only items. Edit the Markdown source to change their state.
- **Editor callout tool.** Insert a NOTE or another supported callout type from the existing editor toolbar.
- **Standalone Mermaid diagrams.** Lowercase `.mmd` files appear in the sidebar, folder listings, and quick switcher. Open them in a read-only diagram view or download their original source. Markdown links open the viewer; image links retain the raw asset URL.

Standalone diagrams use the same strict Mermaid renderer as embedded diagrams. Source reads retain the existing authorization and root-filter checks. Diagram files remain assets: document creation and change proposals targeting `.mmd` are unsupported; edit them with filesystem tools.

No configuration changes or migrations are required. See the [rendering guide](https://github.com/luinstra/plainbase/blob/v0.3.3/docs/operating-plainbase.md#standalone-mermaid-files) for details.
