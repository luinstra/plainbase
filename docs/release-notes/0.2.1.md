A patch release: the first credentialed drills against a real R2 bucket caught an object-mode
signature bug and a slow cold start, and the multi-root sidebar gets its follow-up polish.

## Fixed

- **Object mode: body-carrying PUTs no longer fail with `SignatureDoesNotMatch`.** The client
  emitted `Content-Type` twice under case-variant names (a Ktor header-merge asymmetry), so the
  signed request never matched the wire. Headers the engine manages are now keyed by Ktor's
  exact-case constants, a seam guard refuses case-variant keys at signing time, and the loopback
  signature test asserts every signed header arrives exactly once.
- **Object mode: a truncated GET is refused instead of silently mirrored.** A body shorter than its
  declared `Content-Length` now fails the fetch rather than storing a short file; oversized and
  misdeclared bodies are bounded by an explicit byte budget on both the hydrate and poll paths.
- The advisory `<Size>` element in bucket listings is read leniently: a malformed value downgrades
  to "size unknown" instead of refusing to boot.

## Changed

- **Cold hydrate is materially faster.** Mirror hydration fetches 64 ways in parallel and packs
  chunks by declared bytes instead of fixed counts; the rehearsed drill dropped a 1000-page cold
  start from ~25 s to ~9 s over a residential link, with the deployed-adjacency budget documented
  alongside the numbers.
- **Multi-root sidebar polish.** The root selector is a proper listbox (Enter, Space, Escape, and
  roving focus all work), the tree preserves the server's ordering (`_folder.yaml order:` included)
  within folders-before-pages groups, tree rows drop their icons, and page links render in full-ink
  text. The design handoff spec now matches what ships.
