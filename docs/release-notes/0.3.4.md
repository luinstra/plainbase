Plainbase 0.3.4 adds Markdown negotiation for REST page reads and a direct HTTP agent workflow.

## Added

- **Markdown responses (#52).** Send `Accept: text/markdown` on REST page reads, ordinary document URLs, and collision-loser permalinks to read the indexed full source, while
  the default JSON representation, authentication behavior, ETags, redirects, and structured
  failures remain unchanged. See the [HTTP API reference](https://github.com/luinstra/plainbase/blob/v0.3.4/docs/http-api.md).
- **Direct HTTP agent guide.** The [HTTP agent workflow](https://github.com/luinstra/plainbase/blob/v0.3.4/docs/http-agent-workflow.md)
  shows a practical curl + jq search → read → propose → track flow, plus guarded direct-write guidance.
- **Agent and operator guidance.** Corrected visible-scope 404 handling, unresolved 503 recovery, and
  citation/provenance retention guidance.

No configuration changes or migrations are required. MCP behavior is unchanged; see the [MCP connection guide](https://github.com/luinstra/plainbase/blob/v0.3.4/docs/connect-your-agent.md).
